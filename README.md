# ProductApp

## 1. Thông tin bài tập

- **Tên bài nộp:** ProductApp
- **Chủ đề:** Ứng dụng bán sách
- **Link ứng dụng Expo Snack:** https://snack.expo.dev/@voduyanh/productapp

## 2. Các component

### App.js
Component chính hiển thị danh sách sản phẩm bằng FlatList.

[Mã nguồn App.js](App.js)

### ProductCard.js
Component hiển thị thông tin từng sản phẩm thông qua Props, bao gồm:
- Tên sách
- Hình ảnh
- Giá bán
- Mô tả

[Mã nguồn ProductCard.js](ProductCard.js)
